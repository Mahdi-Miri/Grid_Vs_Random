# Grid_Vs_Random
This Python project optimizes a binary classification neural network using GridSearchCV and RandomizedSearchCV. It tunes hyperparameters like hidden layer units and optimizer for a Keras model, demonstrating model optimization techniques.

Key Features:

Synthetic data generation using scikit-learn.
Keras neural network model creation.
Hyperparameter tuning with GridSearchCV and RandomizedSearchCV.
Model performance evaluation using best parameters and scores.
Technologies:

Scikit-learn, TensorFlow/Keras, Scikeras.
Use Case:

Neural network hyperparameter tuning for improved model performance.
